# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Security is a fundamental design principle of **AgentShield**. If you believe you have found a security vulnerability in this project, please report it to us responsibly:

1. **Email:** Send details to `atpadkarmaruti@gmail.com`.
2. **Subject:** `[SECURITY] AgentShield Vulnerability Report`
3. **Include:**
   - Detailed description of the vulnerability.
   - Minimal reproduction script or command sequence.
   - Potential impact and suggested mitigations.

### Response Timelines
- **Initial Response:** Within 24 hours.
- **Triage & Patch Deployment:** Within 72 hours of verification.

We appreciate responsible disclosure and will credit researchers in our release notes.
